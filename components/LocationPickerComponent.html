Description

The Location picker component renders a searchable dropdown of the account's locations and lets the user create a new location inline. It works as a form control.

When opened it loads the most recently created locations (limited by initialCount). Typing in the search box runs a debounced server-side search. A footer action opens an "Add new location" modal that creates the Location + AccountLocation and selects it on save.

Usage

import { LocationPickerModule } from '@congarevenuecloud/elements';

@NgModule({
imports: [LocationPickerModule, ...]
})
export class AppModule {}

.location-picker {
  &.disabled {
    opacity: 0.65;
    pointer-events: none;
  }

  .custom-asterisk {
    font-size: 8px;
  }

  // Let the Bootstrap .form-control border show and suppress ng-select's own container border so the
  // control matches sibling form fields.
  ng-select.form-control {
    height: calc(1.5em + 0.75rem + 2px);

    .ng-select-container {
      height: 100%;
      min-height: 100%;
      border: none;
      background-color: transparent;
    }
  }
}

// Modal renders outside the component DOM (via BsModalService), so scope asterisk sizing to its dialog class.
.location-picker-modal .custom-asterisk {
  font-size: 8px;
}

// ngx-bootstrap doesn't raise z-index or add a backdrop for stacked modals, so raise this modal above a host modal.
.modal:has(> .modal-dialog.location-picker-modal) {
  z-index: 1065;
}

// Dim the host ourselves when stacked on top of one.
.modal:has(> .modal-dialog:not(.location-picker-modal)) ~ .modal:has(> .modal-dialog.location-picker-modal) {
  background-color: rgba(0, 0, 0, 0.5);
}
