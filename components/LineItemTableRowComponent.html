Description

Line item table row component is used to display line items on cart, quote, and order detail pages.

Note: When the tax feature is integrated, a Sales Tax row is shown automatically per line item. For consumers without tax integration, the row stays hidden — no additional configuration is required.

import { LineItemTableRowModule } from '@congarevenuecloud/elements';

@NgModule({
imports: [LineItemTableRowModule, ...]
})
export class AppModule {}

isFieldEditable
isFieldEditable(view: CartItemView)

This method determines whether a specific field in the cart item view is editable or not editable.

        - `fieldName`: The name of the field to check.
        - `isEditable`: The default editability of the field.

     - For asset line items: editability is determined by line status logic via `lineItemFieldProcessingService`.
     - For non-asset items with `customFieldEditability` map:
       - If field is `false` in map → not editable
       - If field is `true` in map → respect line status-based editability
       - If field not in map → use line status-based editability
     - For non-asset items without `customFieldEditability` map: returns line status-based editability.
Parameters :

  • For asset line items: editability is determined by line status logic via lineItemFieldProcessingService.
  • For non-asset items with customFieldEditability map:
    • If field is false in map → not editable
    • If field is true in map → respect line status-based editability
    • If field not in map → use line status-based editability
  • For non-asset items without customFieldEditability map: returns line status-based editability.
