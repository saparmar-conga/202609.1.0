Description

A single column record as returned by the storefront displayColumns API. FieldName, Section and Sequence are required; every other property narrows the built-in rendering.

ShowForGuest
ShowForGuest: boolean
Type : boolean
Optional

Whether the field is shown to a guest. Omit to keep it visible; set false to hide it from guests. Applied on detail pages (summary, line item, price); list pages do not filter on it.
ShowPopover
ShowPopover: boolean
Type : boolean
Optional

Truncate a long text value and reveal the full text in a hover popover. List sections only. Unlike ShowQuickView, this shows plain text, not a related-record card.
ShowQuickView
ShowQuickView: boolean
Type : boolean
Optional

For a lookup/reference field, show a quick-view popover of the related record (its key fields) on interaction. List and summary sections. Differs from ShowPopover, which reveals long plain text; if both are set, ShowPopover wins and quick-view is disabled.
