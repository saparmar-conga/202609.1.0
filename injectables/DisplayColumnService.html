Description

Maps the storefront displayColumns API onto the table and detail rendering used across the storefront apps. Injected wherever configured columns drive a list, detail summary or line item grid; when nothing is configured toTableColumns returns the built-in columns, so the storefront keeps its default layout.

Usage

import { DisplayColumnService } from '@congarevenuecloud/elements';
constructor(private displayColumnService: DisplayColumnService) { }

// `displayColumns` is the list returned by StorefrontService.getStorefrontDisplayColumns()
const columns = this.displayColumnService.columnsForSection(displayColumns, 'Order List');
options.columns = this.displayColumnService.toTableColumns(columns, this.getDefaultColumns(), (column) => this.displayColumnService.formatColumnValue(column));
