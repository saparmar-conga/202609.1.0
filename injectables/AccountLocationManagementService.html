Description

The AccountLocations service provides methods for managing account locations, enriching each record with its full Location data. It supersedes the deprecated AccountLocationService.

Usage

import { AccountLocationManagementService, AObjectService } from '@congarevenuecloud/ecommerce';

export class MyComponent implements OnInit {
constructor(private accountLocationService: AccountLocationManagementService) {}
}
// or
export class MyService extends AObjectService {
private accountLocationService: AccountLocationManagementService = this.injector.get(AccountLocationManagementService);
}

createAccountLocation
createAccountLocation(accountLocation: AccountLocation, accountId?: string)

Creates a new account location record for the given account and returns the created record with its generated identifier. To create the Location and AccountLocation together, use createLocationWithAccountLocation instead. If no accountId is provided, the current active account is used.

Example:

import { AccountLocationManagementService, AccountLocation } from '@congarevenuecloud/ecommerce';
import { Observable } from 'rxjs';

export class MyComponent implements OnInit {
accountLocation: AccountLocation;
accountLocation$: Observable<AccountLocation>;

constructor(private accountLocationService: AccountLocationManagementService) {}

createAccountLocation(accountLocation: AccountLocation, accountId?: string) {
this.accountLocationService.createAccountLocation(accountLocation, accountId).subscribe(location => this.accountLocation = location);
// or
this.accountLocation$ = this.accountLocationService.createAccountLocation(accountLocation, accountId);
}
}

createLocationWithAccountLocation
createLocationWithAccountLocation(location: Location, accountLocationData?: Partial, accountId?: string)

Creates a new Location and links it to an account through a new AccountLocation, in a single operation. Returns both the created Location and AccountLocation, each with its generated identifier, and sets AccountLocation.Location to the full Location object.

Example:

import { AccountLocationManagementService, Location, AccountLocation } from '@congarevenuecloud/ecommerce';

export class MyComponent implements OnInit {
location: Location;
accountLocation: AccountLocation;

constructor(private accountLocationService: AccountLocationManagementService) {}

createLocationWithAccountLocation(location: Location, accountId?: string) {
const accountLocationData: Partial<AccountLocation> = { Name: 'Primary Location', IsDefault: false };
this.accountLocationService.createLocationWithAccountLocation(location, accountLocationData, accountId)
.subscribe(result => {
this.location = result.location;
this.accountLocation = result.accountLocation;
});
}
}

getAccountLocations
getAccountLocations(accountId?: string, filters?: Array<FieldFilter>, pageSize: number)

Retrieves account locations for the given account, each enriched with its full Location data. An optional list of filters narrows the results, combined with the account filter. When no accountId is provided, the current active account is used.

Example:

import { AccountLocationManagementService, AccountLocation, FieldFilter } from '@congarevenuecloud/ecommerce';
import { FilterOperator } from '@congarevenuecloud/core';
import { Observable } from 'rxjs';

export class MyComponent implements OnInit {
accountLocationList: Array<AccountLocation>;
accountLocationList$: Observable<Array<AccountLocation>>;

constructor(private accountLocationService: AccountLocationManagementService) {}

getAccountLocations(accountId?: string) {
// All locations for the account
this.accountLocationService.getAccountLocations(accountId).subscribe(locations => this.accountLocationList = locations);

// Narrowed by structured filters
const filters: Array<FieldFilter> = [{ field: 'Name', value: 'HQ', filterOperator: FilterOperator.CONTAINS }];
this.accountLocationList$ = this.accountLocationService.getAccountLocations(accountId, filters);
}
}

See FieldFilter for more details on the structure and fields required.

Parameters :
Name Type Optional Default value Description
accountId string Yes

Optional account identifier. If not provided, the current active account is used.
filters Array<FieldFilter> Yes

Optional list of FieldFilter records combined with the account filter.
pageSize number No AccountLocationManagementService.DEFAULT_PAGE_SIZE

Optional maximum number of records to request (defaults to 100).
Returns : Observable<Array<AccountLocation>>

An observable containing an array of AccountLocation records enriched with full Location data.
refreshAccountLocations
refreshAccountLocations(accountId?: string, pageSize: number)

Reloads the cached account locations and emits the fresh list to subscribers of getAccountLocations. When no accountId is provided the currently cached account is reloaded, falling back to the active account.

Example:

import { AccountLocationManagementService } from '@congarevenuecloud/ecommerce';

export class MyComponent implements OnInit {
constructor(private accountLocationService: AccountLocationManagementService) {}

refreshAccountLocations() {
this.accountLocationService.refreshAccountLocations();
}
}
