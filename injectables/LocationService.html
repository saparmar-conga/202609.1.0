createLocation
createLocation(payload: Location)

Creates a new location record and returns the submitted payload merged with the generated identifier. Server-populated fields are not included; use getLocationById to fetch the complete record.

Example:

import { LocationService, Location } from '@congarevenuecloud/ecommerce';
import { Observable } from 'rxjs/Observable';

export class MyComponent implements OnInit {
location: Location;
location$: Observable<Location>;

constructor(private locationService: LocationService) {}

createLocation(payload: Location) {
this.locationService.createLocation(payload).subscribe(location => this.location = location);
// or
this.location$ = this.locationService.createLocation(payload);
}
}
Parameters :

The Location record to create.

An observable containing the submitted payload merged with the generated Id.

getLocationsByFilters
getLocationsByFilters(filters: Array<FieldFilter>, options?: DataQueryOptions)

Retrieves all locations matching the supplied field filters.

Example:

import { LocationService, Location, FieldFilter } from '@congarevenuecloud/ecommerce';
import { FilterOperator } from '@congarevenuecloud/core';
import { Observable } from 'rxjs/Observable';

export class MyComponent implements OnInit {
locations: Array<Location>;
locations$: Observable<Array<Location>>;

constructor(private locationService: LocationService) {}

getLocationsByFilters(city: string) {
const filters: Array<FieldFilter> = [{ field: 'City', value: city, filterOperator: FilterOperator.EQUAL }];
// Return the first page of 20, sorted by name
const options = { Limit: 20, Sort: { FieldName: 'Name', OrderBy: 'Ascending' as const } };
this.locationService.getLocationsByFilters(filters, options).subscribe(locations => this.locations = locations);
// or
this.locations$ = this.locationService.getLocationsByFilters(filters);
}
}

See FieldFilter for more details on the structure and fields required. See DataQueryOptions for more details on the structure and fields required.

Parameters :
Name Type Optional Description
filters Array<FieldFilter> No

The field filters to apply.
options DataQueryOptions Yes

Optional query settings such as select, limit, skip, distinct and sort.
Returns : Observable<Array<Location>>

An observable containing an array of Location records.
