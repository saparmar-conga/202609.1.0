Description

Holds a detail page's action configuration and answers visibility, label and styling questions for the template. Built from the shared defaults scoped to one section, optionally overridden by the storefront displayActions API, and evaluated against the current record stage and user type.

Usage

actions = new DetailActionSet(DetailActionSection.Order, DEFAULT_DETAIL_ACTIONS, () => ({
  stage: get(this.order, 'Status'),
  isLoggedIn: this.isLoggedIn
}));

// merge the storefront override once the API responds
this.actions.applyOverrides(actionsResponse);
@if (actions.isVisible('Present', actionArea.Main)) {
  <button [disabled]="actions.isDisabled('Present', actionArea.Main)" (click)="presentQuote(quote)">
    {{ actions.label('Present', actionArea.Main) | translate }}
  </button>
}

applyOverrides
applyOverrides(overrides: Array<Partial<DetailAction>>)

Applies the storefront displayActions records for this section. A section named in the payload is defined entirely by that payload — its built-in actions are replaced, so anything the payload omits is no longer shown. A section the payload does not mention keeps its built-in defaults. Each configured action still inherits any field it omits from the built-in action of the same Name. See DetailAction for more details on the structure and fields required.
